⚠️ 5 Common Mistakes to Avoid
1. ∈ vs ⊆
2 ∈ A is for an element; {2} ⊆ A is for a subset.
2. Union vs Intersection
Union (∪) = all of A or B; Intersection (∩) = only the purple overlap.
3. Complement & U
A' is always defined relative to the Universal Set U.
4. Difference Order
A - B and B - A are not necessarily equal.
5. Equal vs Equivalent
Equal = identical elements; Equivalent = same count n(A)=n(B).

🏛️ The 4 Pillars of OOP
1. Inheritance & super()

A child class reuses attributes and methods from a parent class. Use super().__init__() to initialize parent attributes cleanly.

class GradStudent(Student):
  def __init__(self, name, branch, thesis):
    super().__init__(name, branch, 101, "7th", "2025")
    self.thesis = thesis
⚠️ Mistake: Forgetting super().__init__() leaves parent attributes unset.
2. Encapsulation (__private)

Bundles data and restricts direct outside modification using private attributes (__marks) and validated getter/setter methods.

class Account:
  def __init__(self, marks):
    self.__marks = marks  # name-mangled
  def get_marks(self): return self.__marks
⚠️ Mistake: Accessing obj.__marks directly raises AttributeError.
3. Abstraction (ABC)

Hides internal complexity and forces subclasses to implement required methods via Python's abc module.

from abc import ABC, abstractmethod
class Person(ABC):
  @abstractmethod
  def role(self): pass
⚠️ Mistake: Instantiating an abstract class directly raises TypeError.
4. Polymorphism (Overriding)

Different classes share the same method name (e.g. introduce()) while each executes its own specialized behavior.

class Mentor(Student):
  def introduce(self):
    return f"Mentor {self.name}"
for p in [s1, mentor1]: print(p.introduce())
⚠️ Mistake: Assuming Python supports C++/Java style method overloading by signature.
Quiz-Ready Reference
⚡ Advanced OOP Essentials (Dunders, Decorators & MRO)
Dunder Methods: __str__ controls print(obj); __repr__ is for debugging; __len__ powers len(obj).
@classmethod & @staticmethod: @classmethod takes cls (factory methods); @staticmethod takes neither self nor cls.
@property: Lets you access a getter method like an attribute (s1.grade without parentheses).
MRO & Multiple Inheritance: Python uses C3 Linearization (Class.__mro__) to resolve method lookup order; check with issubclass(Child, Parent).

Python Sets & OOP FAQ

1. What are Python Sets?
A Set is an unordered collection of unique, hashable items supporting O(1) membership checks and math operations like Union (|), Intersection (&), and Difference (-).
2. What is OOP in Python?
Object-Oriented Programming organizes code into class blueprints and independent object instances using the 4 pillars: Inheritance, Encapsulation, Abstraction, and Polymorphism.
3. How does the Python 3 Compiler work live?
On localhost it uses the Python 3 backend; on static hosting (Vercel) it automatically falls back to Pyodide (CPython WebAssembly) inside your browser with full input() support.
4. What is the difference between self and __init__?
__init__ is the constructor method invoked on object creation, while self refers to the newly allocated object instance so attributes are stored privately in self.__dict__.
